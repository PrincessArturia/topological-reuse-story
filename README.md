# Topological reuse

The story page of a research project by Arthur Boscoli Rodrigues: networks that solve structurally similar problems build
similar circuit shapes, and one network can read those shapes and reuse its own circuits.

**Read it here: https://princessarturia.github.io/topological-reuse-story/**

This repository holds only the built page (`index.html` and the interactive figures in `figures/`). It is generated from the
project's findings and figure library, which live in a separate repository, and it grows as experiments finish.

AI assistance. Arthur Boscoli Rodrigues conceived this research, directs it and is responsible for its content. Claude, an AI
model made by Anthropic, was used throughout: to write and run the code of the experiments, to analyze the results, to build
the figures and to draft text.
